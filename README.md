# ANIMAL CLASH

십이지(十二支) 캐릭터로 싸우는 1인칭 능력 FPS 프로토타입.
혼자 하기는 브라우저만 있으면 되고, 같이 하려면 중계 서버(Node)를 띄웁니다.

---

## 실행

### 앱으로 (권장)

```
npm install     # 처음 한 번
npm start       # 실행
npm run build   # dist/ 에 배포본 만들기
```

앱에서는 브라우저 제약이 없습니다 — 마우스 잠금이 거부되지 않고, `ESC` 로 전체화면이
풀리지 않으며(`F11` 로 켜고 끕니다), 주소창·탭이 없습니다.

메뉴 › 멀티플레이 › **내 컴퓨터에서 서버 열기** 로 중계 서버를 앱 안에서 띄울 수 있습니다.
밖에 있는 친구와 하려면 **설정 › 고급** 에 서버 주소를 넣습니다.

> `npm run build` 로 설치본(.exe)까지 만들려면 **윈도우 개발자 모드**가 켜져 있어야 합니다.
> (설정 › 개인 정보 및 보안 › 개발자용) 꺼져 있으면 `dist/win-unpacked/` 까지만 나오는데,
> 그 폴더를 압축해 그대로 배포해도 됩니다.

### 브라우저로

**혼자 하기** — `게임 실행.bat` 을 더블클릭하거나 `index.html` 을 브라우저로 직접 엽니다.
**같이 하기** — `서버 실행.bat` 을 더블클릭하면 서버가 뜨고 브라우저가 열립니다.

> **주의** — 편집기의 미리보기 창이 아니라 **Chrome/Edge 탭에서 직접** 열어야 합니다.
> 주소창에 `file:///.../index.html` 이 보여야 마우스 잠금(포인터 락)이 동작합니다.
> 미리보기 창은 `data:` 문서라 브라우저가 마우스 잠금을 거부합니다.

`index.html` 과 `three.min.js` 는 **같은 폴더**에 있어야 합니다.
서버로 열면(`http://localhost:3000`) 마우스 잠금 제약도 없습니다.

## 조작

| 키 | 동작 |
|---|---|
| `W A S D` | 이동 (방향키도 가능) |
| `Shift` | 달리기 (전진 중에만) |
| `Space` | 점프 — 도달 높이 1.35m |
| `Ctrl` / `C` | 웅크리기 — 속도 46%, 탄퍼짐 38% 감소 |
| `Q` | 캐릭터 능력 |
| 마우스 좌 / 우 | 사격 / 정조준 |
| `1` `2` / 휠 | 보조 / 주 무기 전환 |
| `R` | 재장전 |
| `[` `]` | 감도 조절 |
| `B` | **이모트 휠** — 열린 뒤 숫자키 또는 클릭 |
| `ESC` | 일시정지 · 메뉴 |

> 브라우저가 `Ctrl+W`(탭 닫기)를 가로채므로, 웅크린 채 이동할 땐 `C` 를 권장합니다.

### 이모트 (춤)

`B` 로 휠을 열고 숫자키나 클릭으로 고릅니다. **막춤 · 플로스 · 박수 · 인사 · 도발 · 앉기** 여섯 가지.

- 추는 동안 카메라가 뒤로 물러나 **3인칭으로 내 춤이 보입니다**. 안 보이면 의미가 절반입니다.
- 움직이거나 쏘거나 점프하면 바로 취소됩니다. 춤추면서 싸울 수는 없습니다.
- 상대 화면에도 같은 춤이 보입니다.

### 전체화면

준비 화면의 **전체화면** 버튼으로 켭니다. 켜는 순간 **키보드 잠금(Keyboard Lock)** 이 함께 걸려
`ESC` 가 브라우저 대신 게임으로 들어옵니다 — 즉 **일시정지만 되고 전체화면은 유지됩니다.**

- 전체화면을 나가려면 `ESC` 를 **길게** 누릅니다. 브라우저가 보장하는 탈출구라 없앨 수 없습니다.
- Chrome·Edge 에서 동작합니다. Firefox·Safari 에는 이 API 가 없어 `ESC` 한 번에 풀립니다.
  그 경우에도 **다시 시작할 때 전체화면이 복원**됩니다.
- `http://localhost` 또는 `https://` 에서만 됩니다.

## 무기

**주 무기 하나 + 보조 무기 하나**를 골라 들어갑니다. 캐릭터 선택 화면 아래쪽에서 고르고,
고른 조합은 저장돼 다음 판에도 그대로 적용됩니다. 게임 안에서는 `2` 가 주 무기, `1` 이 보조입니다.

### 주 무기 (`2`)

| | 발사 | 피해 | 헤드샷 | 탄창 | 사거리 |
|---|---|---|---|---|---|
| 소총 VECTOR-R | 자동 640 RPM | 33 | ×2.2 | 30 / 150 | 90m |
| 샷건 BREACHER | 펌프 75 RPM | 4 **×24탄** | ×1.5 | 8 / 64 | 30m |
| 기관총 REAPER | 자동 850 RPM | 24 | ×1.7 | 60 / 240 | 110m |

### 보조 무기 (`1`)

| | 발사 | 피해 | 헤드샷 | 탄창 | 사거리 |
|---|---|---|---|---|---|
| 권총 SIDEARM | 반자동 420 RPM | 28 | ×2.6 | 12 / 72 | 70m |
| 리볼버 JUDGE | 단발 130 RPM | 62 | ×2.8 | 6 / 36 | 95m |
| 쌍권총 TWINS | 자동 700 RPM | 19 | ×1.9 | 24 / 144 | 55m |

- **샷건**은 한 발에 탄 스물네 개가 나갑니다. 탄이 아무리 많아도 피격 표시와 피해 판정은
  **표적마다 한 번**으로 모아 처리하고, 예광선·탄흔은 네 줄만 그립니다.
- 코앞이라도 **두 방**이 필요합니다 (최대 96). 한 방 처치는 일부러 뺐습니다 —
  붙기만 하면 이기는 총이 되면 다른 총을 들 이유가 없어집니다.

  | 거리 | 평균 피해 | 최소~최대 | 두 방 처치 |
  |---|---|---|---|
  | 2~4m | 96 | 96 | 100% |
  | 6m | 94 | 80~96 | 100% |
  | 9m | 57 | 30~84 | 85% |
  | 13m | 37 | 16~70 | 13% |
  | 18m | 20 | 0~40 | — |
  | 25m | 14 | 0~44 | — |
  | 30m 초과 | 0 | — | 아예 안 닿음 |
- **리볼버**는 두 방이면 끝나지만 초당 두 발입니다. 빗나가면 그대로 집니다.
- **기관총**은 탄창이 60발이라 자주 안 갈아도 되지만, 재장전이 3.4초로 가장 깁니다.

## 구조

```
index.html      게임 전체 (HTML · CSS · JS 단일 파일)
three.min.js    three.js r149 (UMD 빌드, 로컬 사본)
GLTFLoader.js   three.js r147 GLTF 로더 (3D 모델 도입용, 아직 미사용)
server/         중계 서버 (Node + ws) · 게임 파일도 함께 서빙
게임 실행.bat    브라우저로 바로 열기 (혼자 하기)
서버 실행.bat    중계 서버 + 브라우저 (같은 집에서 같이 하기)
터널 실행.bat    중계 서버 + 인터넷 공개 터널 (밖에 있는 친구와)
```

### 설계 메모

- **오프라인 우선** — CDN·모듈·빌드 도구 없이 `file://` 에서 동작해야 합니다.
  ES 모듈과 `fetch` 는 `file://` 에서 차단되므로 클래식 스크립트만 씁니다.
- **수직 설계** — 기본 점프 1.35m / 스카이 리프트 4.05m 를 기준으로 지형 높이를 잡습니다.
- **충돌** — 축 정렬 AABB. 맞닿음을 충돌로 세지 않도록 EPS 여유를 둡니다.
  빠른 이동(돌진 62 u/s)은 스텝을 잘게 나눠 얇은 벽 관통을 막습니다.
- **히트박스** — 머리 1.63~1.91m · 몸통 0.85~1.63m · 다리 0~0.85m.
  눈높이(1.62m)를 머리 **아래**에 두어, 수평 조준은 몸통에 맞고 헤드샷은 조준을 올려야 납니다.
  머리가 눈높이를 덮으면 아무렇게나 쏴도 헤드샷이 나 정밀 조준의 의미가 사라집니다.
- **스폰** — 구조물 안이면 주변 빈 자리를 자동 탐색해 옮깁니다.
- **그림자** — 윗면 8m 이하 물체만 그림자를 드리웁니다 (드로우 콜 절감).

## 친구

오른쪽 친구 창에서 관리합니다. 메뉴 화면에 항상 떠 있고 게임 중에는 가려집니다.

- 내 **친구 코드**(예: `불꽃왕#3A7C`)를 알려주면 상대가 추가할 수 있습니다.
  이름만으로는 겹치므로 네 자리를 붙입니다. 코드를 누르면 복사됩니다.
- 친구가 **접속 중**이면 `1대1` 버튼이 뜹니다. 누르면 초대가 가고,
  상대가 수락하면 둘만의 방이 생겨 바로 대결합니다.
- 상태는 접속 중 · 게임 중 · 오프라인 세 가지로 실시간 갱신됩니다.

## 멀티플레이

**`서버 실행.bat`** 을 더블클릭하면 중계 서버가 뜨고 브라우저가 열립니다.
자세한 내용은 [server/README.md](server/README.md) 를 보세요.

같은 **방 코드**를 넣은 사람끼리 만납니다. 서버 주소는 비워 두면 자동으로 잡힙니다.

### 흐름

처음 실행하면 **이름**을 한 번 정합니다. 이후에는 **설정 → 내 이름** 에서만 바꿉니다.

**접속 화면** → 접속하면 **대기실**(별도 화면) → 방장이 시작 → **다 같이 캐릭터 선택** → 전원 확정 또는 시간 종료 → **동시 입장**

- 가장 먼저 들어온 사람이 방장입니다. 방장이 나가면 다음 사람에게 넘어갑니다.
- 시작·입장 신호는 **방장만** 보낼 수 있습니다 (서버가 막습니다).
  아무나 보내면 남이 고르는 중에 판이 넘어갑니다.
- 선택 중에는 누가 무엇을 골랐는지 카드에 실시간으로 표시됩니다.

### 구조

예전에는 브라우저끼리 직접(P2P) 연결했지만, 그러면 **상대에게 내 IP 주소가 그대로 보입니다.**
지금은 중계 서버를 거칩니다 — 서로의 주소는 모르고 서버 주소만 압니다.

- 위치는 20Hz 로 보내고 100ms 지연 보간으로 그립니다.
- 사격은 **쏜 쪽이 판정**하고 맞은 쪽이 피해를 적용합니다 (favor the shooter).
- 능력 12종이 모두 상대에게 걸립니다. 상태이상(석화·둔화·무장 해제·최대 체력 감소)은
  **건 사람이 통보하고 걸린 사람이 적용**한 뒤, 상태 비트를 자기 위치 패킷에 실어 되돌립니다.
  그래야 제3자 화면에도 어지러움 표시와 사라진 총이 똑같이 보입니다.
- 서버가 `id`·`from` 을 덮어쓰므로 **남인 척하기는 막힙니다.**

### 알려진 한계

- **치팅 방어 없음** — 서버는 메시지를 옮길 뿐 게임 판정을 하지 않습니다.
  콘솔로 무적이 되거나 한 방에 죽이는 건 여전히 가능합니다.
  막으려면 서버가 물리와 판정을 직접 굴려야 합니다(서버 권위 구조).
- 팀·라운드 규칙이 아직 없습니다 (전원 자유 대전).
- 3D 모델·텍스처·음악 없음 (도형과 합성음으로만 구성).
